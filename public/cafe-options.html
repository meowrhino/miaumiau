café — opciones técnicas

El mismo edificio (el café) renderizado con 5 métodos distintos. Cada uno tiene tradeoff distinto en calidad, consistencia, tiempo de implementación y dependencias externas. La columna 1 es lo que tienes hoy en producción.

1. Procedural Fast

Lo de hoy. Pixel-art dibujado con primitivas Canvas2D (rect, tri, px) en sprites.js. ~40 ops por casita.

Tiempo: ya hecho.
Pros: 0 deps, 100% propio, animable runtime.
Contras: simple, repetitivo entre zonas.

2. Procedural detallado ~6h

Mismo método pero pintado con muchísimo más cariño: tejas individuales, vidriera con paneles, persianas, lámpara colgante, marquesina con flecos, plantas. ~300 ops.

Tiempo: ~1h por casita = 6h las 6 zonas.
Pros: 0 deps, máximo control, animable runtime.
Contras: pixel-art a ciegas dentro de JS — lentito iterar visualmente.

3. SVG vectorial ~4h

Path/rect SVG con gradients, sin pixelart. Look más "ilustración cozy", menos "8-bit". Escala perfecta a cualquier resolución. Igual que ya se usa para los gatos.

Tiempo: ~40min por casita = 4h.
Pros: 0 deps, escala infinita, fácil editar, accesible.
Contras: rompe estética pixel-art (¿o quizás encaje mejor con el gato SVG?).

4. AI image-gen Externo

Generar cada casita con DALL-E / Midjourney / SDXL. Prompt fijado para consistencia. Sale PNG transparente directamente.

5. Asset pack Externo

Pack pixel-art ya curado de itch.io. Estilo coherente garantizado. Ejemplo aquí: Cozy Farm de shubibubi (16×16 top-down, $3.99 versión comercial).

Tiempo: ~1h descargar + integrar todo el pueblo.
Pros: consistencia perfecta, look profesional.
Contras: te casas con ese estilo; licencia (gratis = no comercial); top-down implica pivot iso→top.
Otros packs: Sprout Lands, Serene Village.
